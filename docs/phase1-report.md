# My Time — Phase 1 実装完了レポート

作成：2026-10-31（Claude）／ 状態：**レビュー待ち**（Phase 2 には未着手）

## 1. 実装済み機能（実際に操作できるもの）
- **5タブ**（ホーム／カレンダー／タスク／分析／その他）。初期画面はホーム。ライト／ダーク／システム、文字サイズ（iOSの文字サイズ設定に追従＋アプリ内で小〜特大）、Reduce Motion、セーフエリア対応。
- **ホーム**：左上に日付1箇所（`12日(月)`、28px太字）。右に単独アイコンの1日⇔2日切替・検索・＋（タスク/予定）・その他。幅が360px未満では検索をその他メニューへ。
  - 上段：左端の表示日に時刻指定されたタスク一覧（独立スクロール、行高 約60pt）。
  - 境界ハンドル：**上下ドラッグのみ**で切替（指に追従→スプリング収束、速度でも判定）。タップは何もしない。代替操作は「その他」メニューとキーボード↑↓。
  - 拡張時：上段は浮遊カードに変形（実行中＝緑の充填〔実績があれば実績、なければ理想〕、次のタスク＝横長カード、何もなければ空カード。完全非表示にしない）。表示日数は1〜7日を選択。
  - 日付は時間軸・タスク一覧どちらの横スワイプでも1日単位で移動し、上段は常に左端の日付。
- **タスク行**：アイコン＋理想進捗リング、名前、右端の時刻（未開始＝予定開始／実行中＝予定終了または「予測」／完了＝実績終了）。遅延時はアイコンが「!」、終了時刻がゆっくり明滅＋`+N分`（Reduce Motion 時は明滅なし）。AR バッジの表示部品あり（予約操作は Phase 2）。
- **長押し進捗（参考画像準拠）**：約380msの長押しで行が浮き、緑グラデーションのカプセルに変形。初期値＝実績（なければ理想）、横ドラッグで数値と充填が追従、指を離したときに1回だけ保存。ドラッグなし長押し・`pointercancel` は記録しない。100%で離すと「終了しますか？」→承認時のみ完了。サブタスクを持つ親は揺れて案内のみ。
- **タスク詳細シート**（下から、ドラッグで閉じる）：アイコン・大タイトル、開始／一時停止／再開／終了／完了取り消し／開始取り消し、予定・実績・作業時間・予測終了・遅延、カレンダー、進捗（理想／実績）、サブタスク（追加・完了・削除、完了時刻）、実績ログ（作業区間＋操作ログ）、メモ、削除（確認アラート）。
- **作成・編集**：タスク（実施/確認、アイコン、日時、カレンダー、カテゴリ、メモ。実施⇔確認は変換前に確認し実績は保持）、予定（日をまたぐ予定可、重なりを警告し空き時間を**提案**、既存予定は動かさない、削除は確認）。
- **時間軸**：1日／2日／拡張時1〜7日、カレンダータブの日／2日（初期）／週／月。赤い現在時刻線と時刻ラベルは**今日の列だけ**。重なり予定の列分割、日またぎ予定の切り分け表示、ピンチ／トラックパッドで時間軸だけ拡大縮小（ページ全体はズームしない）、長押し→ドラッグで15分刻み移動（複数日表示では日も移動）、移動せず離すと編集／複製／削除のメニュー。
- **遅延描画**：未完了で予定終了を過ぎたタスクは現在時刻まで延長（オレンジ斜線）し他の予定の上に重ね、予測終了は青い点線。延長・予測範囲と重なる後続予定はグレー。元の予定時刻は変更しない。
- **タスクタブ**：検索、その他メニュー、実施/確認切替、「未設定」とカテゴリ別の一覧、完了済みの表示切替。
- **分析（最小限・実データ）**：今日の完了率と作業時間のみ。他は「準備中」と明記。
- **その他**：外観・文字サイズ、カレンダー一覧、Google／同期／Driveは「未設定・準備中」と明記、未同期件数・端末内データ件数。
- **保存**：Dexie（IndexedDB）。操作ごとに本体＋操作ログ＋未同期キュー（冪等ID付き）を1トランザクションで保存。Zodで検証。初回は空のカレンダー3つ（一般／授業／アルバイト）だけを作り、既存データは上書きしない。**自動削除は無効**。
- **PWA**：manifest、独自アイコン、Service Worker（Workbox）でオフライン起動。

## 3. 主要な設計判断
- 計算はすべて `packages/domain` の純粋関数（UIから分離・単体テスト済み）。
- 完了の取り消しは「一時停止」に戻す（取り消しまでの時間を作業時間として捏造しないため）。
- ETAは「実行中・実績0%超100%未満・根拠の作業時間2分以上」のときだけ。それ以外は「未算出／算出中」。
- ジェスチャーは1つだけが主導権を持つロック（`gestures/gestureLock.ts`）で、日付スワイプ・ハンドル・長押しスライド・予定ドラッグが干渉しないようにした。iOS Safari向けに、必要な間だけ非passiveの touchmove でスクロールを止める。
- 閉じるアニメーション中のシート／アラートはタップを透過（WebKitテストで、連続操作が背景に吸われる不具合を発見して修正）。
