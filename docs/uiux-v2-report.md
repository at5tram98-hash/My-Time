## テスト結果

2026-11-02 実行（CI と同じ設定：1ワーカー）

| 項目 | 結果 |
|---|---|
| 型チェック（全パッケージ）・リント | 合格 |
| 単体テスト（ドメイン・Web） | 109件 合格（期間集計・複数通知・Studio の単位と進捗を追加） |
| API テスト（Workers + D1） | 42件 合格（v2 のデータ拡張の互換、お知らせ削除の可否を追加） |
| E2E（Chromium の iPhone 15 Pro 相当 + WebKit） | 148件 合格・4件スキップ（2本指ピンチ・pointercancel など Chromium の CDP タッチが必要なものを WebKit で省略） |
| サーバー連携 E2E（ローカル Worker + 模擬 Google、Chromium + WebKit） | 6件 合格 |
| キャプチャ | `docs/screenshots/v2/`（ライト・ダーク、エディター、情報確認、Studio、分析） |

テストで見つけて直した不具合：
- タブバーの指スライドがタッチで効かない（押したボタンのキャプチャ解除が親に伝わり、操作が取り消されていた）
- マウスで行をスワイプすると、直後の click で行が閉じる
- 共通エディターに重なりの警告がなかった（v1 にあった機能の移植漏れ）
- 「キャンセル」で未保存の変更を確認せずに閉じていた
- 色の自由入力に読み上げ名がなかった
- 同期の詳細シートと状態表示で testid が重複
- ダークで分析の期間セグメントの選択が見えにくい

## 既存の挙動からの変更点（v2 の承認内容による）

- ホームのタスク一覧は「左右の余白なし」から、Q13 のガラスの枠（左右 8px）に変わりました。枠の中の行は全幅です。
- ホームの2日表示は両日の見出しを表示します。
- 予定・タスクをタップすると、まず情報確認が開きます（編集は鉛筆ボタン）。
- 旧形式の未知のアイコン値は、選択なしで表示し、保存しても書き換えません（従来どおり）。

## 保証できないこと（PWA の制約）

- 指先の振動（iOS Safari は非対応）
- アプリを閉じている間の AR の自動開始（サーバーからの通知でお知らせのみ）
- 通知が届く正確な時刻
