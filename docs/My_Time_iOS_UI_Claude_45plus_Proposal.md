## 3. 今日の画面（1日だけ・左右レーン）の仕様

```
┌──────────────────────────────────────┐
│ 2026年10月                    🔍 … ⚙︎ │  ← 日付は1か所。今日以外は「今日へ」
│ 12日 月曜日                           │
│ ┌──────────────────────────────────┐ │
│ │◯ 実行中 統計のレポート 40分・40%  ⏸ ✓│ │  ← 今やること（1枚だけ）
│ └──────────────────────────────────┘ │
│ [⚠注意 3][📥未割当 2][☑タスク 0/4][☀余白 54%] ⌄ │ ← 状況（タップで詳細のシート）
├─────┬──────────────┬─────────────────┤
│     │ 予定 3        ┆ タスク 4         │  ← 見出しタップで片方を広く
│10:00│               ┆ ■統計のレポート    │
│10:40│───────────────┼──────────── 現在 │
│12:00│               ┆ ○奨学金の書類を確認 │  ← 確認は丸いピル
│13:00│ ▮経済学 3-201  ┆                  │
│18:05│ ▨移動 25分     ┆ ▮出勤の準備（色線） │  ← 予定につながる準備は予定の色の線
│18:30│ ▮GU 勤務       ┆                  │
└─────┴──────────────┴─────────────────┘
        [ 今日 | カレンダー | タスク | 振り返り ]  (＋)
```

- **左のレーン**：時間の決まった予定（授業・勤務・外出・取り込んだ予定）。移動時間がある予定は直前に斜線の「移動」。
- **右のレーン**：タスク、作業枠（日時付きサブタスク・破線）、確認タスク（丸いピル）。
- **同じ時刻**：左右は別々に重なりを並べるので、予定とタスクが同じ時刻でも互いに細くならない（E2E「予定は左、タスクは右」で幅120px以上を確認）。同じレーンの中で重なると、従来どおり横に分ける。
- **狭い画面**：既定は左52%・右48%。見出しのタップで「予定を広く（68%）」「タスクを広く（34%）」。タイトルは1行で省略し、タップで詳細。320px で横スクロールが出ないことを E2E で確認。
- **予定を開いたとき**：情報シートに専門カード（要点→「詳しく」）・時間をずらすボタン・準備や関連タスクの一覧・記録（入力元・最終更新・送信待ち）。
- **時間の衝突**：予定どうしは「気づいたこと」に理由つきで出すだけ（自動で動かさない）。タスクが予定と重なると、空きへ移す案を差分で示す。
- **未割当**：時間を決めていないタスクはチップ「未割当」と「タスク」タブのスマートリスト「未割当」。期限の近い順。1回のタップで空き時間の案→「この内容で変更」。
- 1日/2日の切替は**削除**。日付は横スワイプ・メニューの「日付を選択」。

## 4. 改善案（IOS-001〜IOS-050）

各案の書式：②現状の課題・証拠／③改善（変更前→変更後）／④HIG・My Money との関係／⑤状態／⑥アニメーション／⑦範囲／⑧受け入れ条件と検証。
「検証」は **E2E**（Playwright：Chromium の iPhone 15 Pro 相当と WebKit）、**単体**（Vitest）、**目視**（`docs/screenshots/redesign/`）、**未検証**（実機が必要）で示す。

### Design（17件）

#### IOS-001 ｜ Design ｜ 今日の情報の順番を「日付→今やること→状況→時刻軸」に
- ② 旧ホームは日付の下にすぐタスク一覧があり、今どれをやるかを一覧から探す必要があった（`HomeScreen.tsx` 旧版）。
- ③ 変更前：日付→タスク一覧→つまみ→時間軸。変更後：日付→「今やること」1枚→状況チップ→左右レーン。
- ④ 「概要→重要な情報→詳細」（ヘルスケアの概要の考え方）を、1日の行動に当てはめた。
- ⑤ 通常／何もない日（「この後の予定はありません」＋追加）／別の日（「今日へ」）。
- ⑥ 要約の開閉だけ動く（IOS-038）。
- ⑦ `features/home/HomeScreen.tsx`、`styles/today.css`。
- ⑧ 開いた直後に「今やること」が1件だけ見える。E2E「今やること：次のタスクを1回のタップで開始できる」。目視 light/dark-01。

#### IOS-002 ｜ Design ｜ 「今やること」カード
- ② 実行中・次のタスクは旧「コンパクト表示」のカプセルにしか出ず、つまみを操作しないと見えなかった。
- ③ 実行中なら経過時間・実績％と停止/完了。そうでなければ「次にやること」「出発」「予定の最中」「時間を決める」「この後」のどれか1件と、その場の主操作を1つ。
- ④ 主要な操作を1つに絞る（HIG のボタンの考え方）。My Money の今日タブで目標と入力を1枚にまとめた構成を参考にした。
- ⑤ continue / start / leave / event / plan / free の6状態（`data-kind`）。
- ⑥ ボタンの押下で縮む（IOS-045）。
- ⑦ `NowCard`、`packages/domain/src/planner.ts` の `nextAction`。
- ⑧ 単体「P24：実行中 > まもなく始まるタスク > 出発 > 予定」。E2E で start→continue に変わる。

#### IOS-003 ｜ Design ｜ 状況チップ（注意・未割当・タスク・余白）と折りたたみ

- ⑤ 注意：あり（橙）／なし（灰）。未割当：あり（藍）／0。たたむ・広げる。
- ⑥ 高さのアニメーション（IOS-038）。
- ⑦ `HomeScreen.tsx` `Chip`、`settings.todaySummaryCollapsed`。
- ⑧ 各チップの操作領域は高さ36px＋余白（チップの間隔込みで44px相当）。E2E で chip-issues / chip-inbox / chip-tasks を操作。

## 11. 既知の制約・やっていないこと

- **ChatGPT・外部カレンダー・シフトボードとの連携はしていない**（指示により除外）。文章の読み取りは規則ベースのため、書き方によっては読み取れない（読み取れないと案内する）。
- 旧ホームの上下分割・つまみ・コンパクト表示（Dynamic Island 風カプセル）・1日/2日切替は**廃止**した。長押しの進捗入力は「今日のタスク一覧」と「タスク」タブで使える。
- 祝日・長期休業の自動判定（S04）、店の営業時間の取得（S13）、交通情報（S17）はしていない（未入力・未確認として扱う）。
- iPhone 実機・VoiceOver・ホーム画面のショートカット・Push の受信は**未検証**。
