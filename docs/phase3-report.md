## 2. Phase 3 の変更（既存の機能・タブ順・保存形式は維持）

- **アイコンの全面刷新**
  - アプリが表示するアイコンを、すべて `Icon.tsx` の独自 SVG（24 グリッド・丸端）に統一した。
  - 絵文字や記号の文字でアイコンを表していた箇所はなくした（タスク、確認タスク、時間軸、浮遊カード、検索、月表示、カレンダー、取り込み、オンボーディング、お知らせ、タブの注意印、フラグ、優先度）。
  - アイコンの選択画面も新しい SVG だけを並べ、日本語の名前を付けた。
  - タイトル・メモに入力された絵文字は変えていない。
- **Liquid Glass 風のタブバー**
  - 画面下に浮かぶ丸い帯で、半透明の素材とぼかし（`-webkit-` 付きの指定も併記）、縁の光、内側のハイライト、影を付けた。
  - 選択中のタブは、移動するカプセル・太い線・太いラベル・`aria-current` で示す。
  - 押したときに小さく沈む反応を付けた。
  - ぼかしが使えない環境、透明度を下げる設定、コントラストを上げる設定では不透明な帯に切り替わる。動きを減らす設定ではカプセルを動かさない。
  - 横向きではラベルをアイコンの横に並べ、帯を低くする。幅の狭い画面では余白を詰める。
  - 下の余白はトークン `--tabbar-space` の1か所で確保した。
  - これは Web での近似であり、ネイティブの光学効果を再現したものではない。
- **ドラッグ中の端の自動スクロール**
  - 時間軸で予定を運んでいる間、指を上端・下端に近づけると自動で流れる。タブバーの裏側は端に含めない。
  - 静止した長押しでは流さない。
- **性能**
  - タブを切り替えても、隠れている画面は描き直さない（UI の文脈を分け、各画面を memo 化）。
  - タスク一覧は見えている付近だけを描く。
  - 時間軸には表示範囲のタスクだけを渡す（`tasksForRange`）。
- **アクセシビリティ・文言**
  - 操作できる要素すべてに名前があることを検査で確認した。
  - 文字を拡大したときに行の見出しが1文字ずつ縦に並ぶ問題を直した。
  - 「その他 › カレンダー」のような記号の案内を、文章に置き換えた。
  - 「使える範囲と制限」（オフライン、通知、バックアップ、30日後の期限削除の**現在の状態**）を追加した。期限削除が停止中なのに削除されると読める文言も直した。

## 3. 旧アイコン → 新アイコンの対応と互換方針

- 保存形式は変えていない（`icon` は文字列のまま。schema の変更も migration もない）。
- 新しく選んだものは安定した ID で保存する。
- 旧レコード・旧バックアップ・旧移行ファイルの絵文字は、表示するときだけ `resolveItemIcon()` で読み替える。**保存値は書き換えない**ので、一括更新も同期の大量発生も起きない。
- 未知の値は「その他」（`circle`）で表示し、元の値は残す。
- 編集画面で変更せずに保存すると、元の値のまま残る。別のアイコンを選んだ記録だけが新しい ID になる（E2E で確認済み）。
- 既知の制約：旧版のアプリ（キャッシュが更新される前の端末）が新しい ID を受け取ると、アイコンの位置に「book」などの文字が表示される。アプリが更新されれば解消する。
