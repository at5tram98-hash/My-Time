### 修正したこと

1. **起動すると真っ白になる（重大）**：保存用の項目名 `entity` が Core Data の予約語と重なり、`entity == "calendar"` の検索がすべて失敗していた。項目名を `entityName` に変更（`@Attribute(originalName: "entity")` で既存データはそのまま引き継ぐ）。
2. **今日の状況チップが画面の右にはみ出す**：「余白」と「要約をたたむ」が画面外に隠れていた。幅に収まらないときは「今日のタスク」→「今日」と短くし、それでも入らない（大きな文字サイズ）ときだけ横スクロールにした。

## 既知の注意点

- 締切は Web 版の保存形式（`extra.spec.details.dueAt`）に合わせているため、「種類」を選んだタスクだけに設定できる。
- 繰り返し予定の新規作成は「毎日・毎週（作成日の曜日）・毎月」の基本形のみ。Web で作った複雑な繰り返しは読み込み・表示・削除でき、編集で繰り返しの種類を変えない限り内容は保たれる。
- 無料の Personal Team では7日ごとに入れ直しが必要。
