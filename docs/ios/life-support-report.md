## 5. 実装できなかった・制限のある機能

- **アプリが動いていない間の更新・終了**：Live Activity をサーバーから更新するプッシュ（APNs）にはサーバーと証明書が必要で、今回は作っていない。そのため終了時刻を `staleDate` に入れ「終了」と表示し、次にアプリを開いた時に消す。予定変更も、アプリを開いた時（または前面中の1分ごと）に反映される。
- **予約開始は iOS 26 以降のみ**。それより前の iOS では、アプリを開いていないと開始時刻に自動では出ない（通知で代替）。
- **ダイナミックアイランドに何を出すかは OS が決める**。アプリが決めるのは開始する順番と重要度だけ。
- **アラーム音**：AlarmKit はアプリに入れた音しか選べないため、生成した3種＋システム標準。時計アプリの音一覧は使えない。
- **通知は目覚ましと同等ではない**：AlarmKit が使えない（iOS 25 以前・許可なし）ときの代替通知は、マナーモードや集中モードで鳴らないことがある（画面にも明記）。
- **勤務場所の位置情報**：住所の文字は保存するが、地図での選択・到着の自動検知は未実装。
- **Web 版（PWA）との同期**：清掃・朝・Live Activity・種類の設定・確定給与は設定レコードの iOS 専用キー、勤務先の給与条件は勤務先レコードの `pay` に保存。Web 版は知らない項目を残したまま無視するので消えないが、Web 版の画面では編集・表示できない。

## 6. 既存データとの互換性

- 既存の予定・タスクの ID と内容は変更しない。新しいデータは追加のキー（`iosCleaning`・`iosMorning`・`iosLiveActivity`・`iosSpecSettings`・`iosConfirmedPay`、勤務先の `pay`、予定の `extra.attendance(s)`）。
- 古いデータに項目がなくても既定値で読む（単体テストで確認）。破壊的な移行処理はなし。
- 新しい種類（清掃 S26・朝 S27）は Web 版では「種類なし」として扱われる。
- 何度保存しても1件のまま（キーごとに置き換え、履歴は ID で重複を除く）。
