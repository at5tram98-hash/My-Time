# My Time — Phase 2 実装完了レポート

作成：2026-11-01（Claude）／ 状態：**レビュー待ち**（Phase 3 には未着手）

## 1. 実装済み機能（実際に操作できるもの）

### カレンダー（高度）
- **カレンダー管理**（その他 › カレンダー）：追加・名前・色・アイコン・表示/非表示・並べ替え・削除（予定が残っているもの／最後の1つは削除不可）。非表示にすると時間軸・月表示から消える。
- **繰り返し**：毎日／毎週（曜日指定）／毎月／毎年、間隔、終了日。変更・削除・ドラッグ移動のときに「この予定のみ／これ以降のすべての予定」を選ぶ（iOS カレンダーと同じ）。親の記録は1件のまま、回ごとの変更・取消は例外として保存。
- **別の日にコピー**：ミニカレンダーで複数日を選択（既存予定がある日には点）。重なる日はコピー前に確認。
- **重なり**：保存前に「時間が重なっています」→ 空き時間の**提案**／重ねて保存／キャンセル。提案の範囲・刻みは設定可能（既定 7〜23時・15分）。既存予定は動かさない。
- **授業**：科目（登録済みから選択・新規入力）、教室、課題（内容・提出方法・提出先・期限）、小テスト（名前・日時）。
- **アルバイト**：勤務先の登録（その他 › 勤務先）、勤務先ごとの事前通知時間（既定2時間前）。
- **「終了したらすぐ隠す」**：日付をまたぐ予定にだけ表示されるスイッチ（夜勤など）。ユーザー回答どおり、**フラグを付けた予定だけ**が終了直後に通常画面から隠れる。

### タスク（高度）
- 優先度、タグ、フラグ、通知（◯分前）、場所、繰り返し（完了すると次回を作成）、作業時間の見積もり。
- **AR（自動開始・自動終了の予約）**：詳細シートの開始/終了ボタンを長押し → 予約シート。予約時刻を過ぎて開いた場合も、予約した時刻で開始/終了を記録。行と詳細に AR バッジ。
- **未開始通知**：予定開始の5分後に「タスク未開始。タスクを修正するか、今すぐ開始してください。」（1回だけ）。
- **ETA**：Phase 1 の条件（実行中・実績0〜100%・根拠2分以上）を維持。

### 授業 → 課題・テスト対策タスク
- 授業予定を保存するとき、まだタスクになっていない課題・小テストがあれば**確認ダイアログ**を出し、「作成」を選んだ場合だけタスクを作る。
- ID は `class:<予定ID>:assignment:<キー>` で固定。保存し直しても重複しない（E2E で確認）。授業を削除してもタスクは残す。
- 小テストからは「テスト対策」タスク＋サブタスク「詳細なテスト対策」。
- 作業時間が未入力のものは「タスク」タブの**未設定**に入る。

### 分析・設定・初回セットアップ
- **分析**：フィットネス風のリング（完了率・遅延率）、実行時間、週の切り替え、曜日ごとのリングと棒グラフ。授業・アルバイトの予定は除外。一時停止・自動開始/終了のタスクは設定で含めるまで除外し、その件数を表示。
- **その他**：アカウントと同期、Drive バックアップ、期間指定の復元、お知らせ（「!」バッジ）、外観、文字サイズ、拡張時の日数、カレンダー／科目／勤務先、空き時間の提案範囲、通知、取り込み、端末内データ件数。
- **初回セットアップ**（7枚）：ようこそ → Google ログイン（あとでも可）→ カレンダー → 授業と勤務先 → 通知 → 外観 → 使い方。

### Google ログイン・同期（サーバー：Cloudflare Workers + D1、アプリと同じ URL で配信）
- OAuth 2.0 認可コード + PKCE(S256) + 1回限りの state。ID トークンを JWKS(RS256) で検証（aud/iss/exp）。リフレッシュトークンは AES-GCM で暗号化して保存。ブラウザには HttpOnly・SameSite=Lax の Cookie のみ（DB にはハッシュ）。書き込み要求には独自ヘッダー必須（CSRF 対策）。権限は `drive.file`（My Time が作ったファイルのみ）。
- 同期：端末に先に保存 → 送信キュー（opId で冪等）→ version で競合検出（新しい方を採用、古い側には最新記録を返す）→ server_seq カーソルで受信。未送信の変更がある記録は受信で上書きしない。失敗時は指数バックオフ＋ジッター（最大10分）、3回失敗で「!」。
- オフラインでも全機能が使え、オンラインに戻ると自動送信。

### Drive バックアップ・期限削除・復元
- **毎日 22:00（日本時間、cron `0 13 * * *`）**：全データのスナップショットを「My Time Backup」フォルダーに保存 → **ダウンロードし直して件数と SHA-256 を照合**できたものだけを「確認済み」にする。「今すぐバックアップ」もあり。
- **期限削除（30日）**は次の条件をすべて満たすときだけ：その日の日次バックアップが確認済み → 対象を**アーカイブとして別保存し、読み戻し確認** → version 条件付きで論理削除・台帳に記録。バックアップ失敗・読み戻し不一致の日は**1件も削除しない**。繰り返し予定は親を残し、該当回だけを外す。提出期限だけの課題は削除しない（未確定事項 #1）。
- **期間指定の復元**：アーカイブを確認してから通常画面に戻して表示（バナー「過去のデータを◯件表示中」）。表示中は期限処理の対象外。「閲覧を終了」で通常画面から外れるが、**Drive のファイルは残る**。
- バックアップ一覧：古い日次バックアップは手動で削除可。**アーカイブと最新の確認済みは削除不可**（サーバー側でも拒否）。Drive の空き容量が少ないと警告。

### 通知
- Web Push（RFC 8291 暗号化 + VAPID、外部ライブラリなし）。5分ごとの cron で、タスク通知・未開始通知・勤務前通知・毎日20時の「未設定タスク」案内を送る（重複送信防止つき）。アプリを開いているときはアプリ内バナーでも表示。
- iPhone では「ホーム画面に追加」したアプリでのみ通知を受け取れる（iOS の仕様）。

### 予定の取り込み（TimeTree など）
- TimeTree など他アプリから書き出した `.ics` ファイル、またはテキストの貼り付け（例：`10/14 18:00-20:00 ごはん @相手`、`22:00-6:00` の日またぎも可）。
- 1件ずつ「取り込む／編集／スキップ」。同じ予定（開始・終了・タイトルが一致）は更新し、時間が重なるだけの予定は警告して既存予定は変更しない。非公式な認証回避や自動ログインはしない。

## 2. 未実装・未決定・既知の制限（隠さない）
- **本番の Google / Cloudflare は未接続**。設定には利用者の操作が必要（`docs/setup-cloudflare-google.md`）。GitHub Pages 版はサーバーがないため、同期・バックアップ・通知は「この配信先では利用できません」と表示し、端末内だけで動く。

- TimeTree の直接連携（API）はなし。書き出したファイルかテキストの貼り付けのみ。
- 未確定事項は `docs/open-questions.md`（#12〜#17 を追加）。

## 3. 変更ファイル／主要な設計判断
- 追加：`apps/api`（Workers・D1 マイグレーション・認証・同期・バックアップ・通知・テスト）、`packages/domain` の recurrence / special / retention / analysis / importParse / ops / snapshot、`apps/web/src/sync`、`features/onboarding`、`features/other/{ManagePages,DataPages,ImportSheet,NotificationSettings}`、`features/calendar/CopyEventSheet`、`features/tasks/AutoReserveSheet`、`sw.ts`（独自 Service Worker）、`tests/e2e/phase2.spec.ts`、`tests/stack/`、`tests/fake-google/`。

- Workers は UTC で動くため、全入口で利用者のタイムゾーン（Asia/Tokyo）に切り替えて日付を判定。

| `pnpm e2e:stack`（ローカル Worker + 模擬 Google、Chromium + WebKit） | **2件成功** |

**データ保護ゲートの確認内容**（API テスト＋サーバー連携 E2E）：バックアップ保存失敗の日は削除しない／読み戻しが一致しない日は削除しない／確認済みの日だけ期限切れ（45日前）を削除し、今日のデータは残る／同じ日に再実行しても何も起きない／復元表示中は再削除しない／「閲覧を終了」後も Drive のアーカイブが残る／アーカイブと最新の確認済みバックアップは削除できない／2台目の端末に同期・削除が反映される／未送信の変更は受信で上書きされない。

**この過程で見つけて直した不具合**：初回セットアップで「次へ」を素早く2回押すと科目・勤務先が二重登録される、カードの切り替え中のタップで手順が1枚飛ぶ（どちらも修正し、8回連続実行で確認）。画面確認で見つけた、失敗理由が技術的な文のまま表示される・長期の遅延が「+64192分」になる・小テスト名の入力欄が狭い、の3点も修正。
